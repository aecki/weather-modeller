# Official RhiresD byte-range index

Versioned metadata for all final annual days, 1961–2025. No rainfall values or raw annual files are stored here. Each day identifies its official NetCDF byte range and two SHA-256 hashes (raw chunk and normalized grid). Every range was checked against the independent NetCDF decoder. See docs/full-calendar.md and scripts/index_rainfall_archive.py.

Source: MeteoSwiss. Provider URLs, full-file hashes and versions are in each annual metadata file.
